1. Connect to the Pi

From your Mac terminal: ssh tammyh@192.168.0.117 If SSH key error after re-flash: ssh-keygen -R 192.168.0.117 ssh-keygen -R skirtpi4.local

2. Create the Project Folder

4. Create Files on the Pi (cat method)

Template — replace FILENAME.py and paste your code between the lines: cat > ~/project-sparkle/FILENAME.py << 'EOF' # paste your code here EOF

5. Run Test Scripts

sudo python3 ~/project-sparkle/strip_test.py sudo python3 ~/project-sparkle/rings_test.py sudo python3 ~/project-sparkle/chain_test.py python3 ~/project-sparkle/mic_test.py

6. Run the Main Dress Program

sudo python3 ~/project-sparkle/sparkle.py

7. Set Up Auto-Boot Service

cat << 'EOF' | sudo tee /etc/systemd/system/sparkle.service [Unit] Description=Project Sparkle LED Dress After=multi-user.target [Service] Type=simple User=root WorkingDirectory=/home/tammyh/project-sparkle ExecStart=/usr/bin/python3 /home/tammyh/project-sparkle/sparkle.py Restart=on-failure RestartSec=5 [Install] WantedBy=multi-user.target EOF sudo systemctl daemon-reload sudo systemctl enable sparkle.service sudo systemctl start sparkle.service

8. Safe Shutdown

sudo shutdown now
⚠️ Always shut down properly before unplugging the Pi. Pulling power without shutting down can corrupt the SD card!
⚙️ sparkle.py Config — What to Change and When
Setting Current Value What it does When to change
BRIGHTNESS 0.3 (30%) How bright the LEDs are Increase to 0.5 for showcase, keep at 0.3 for testing
USE_MIC False Turns mic monitoring on/off Change to True when mic is plugged in and tested
USE_DISTANCE False Turns distance sensor on/off Change to True when sensor is wired to GPIO23/24
USE_MATRIX False Turns 8×32 matrix on/off Change to True when matrix is wired to GPIO10
MIC_THRESHOLD 3000 How loud before clap triggers Lower if not triggering, raise if triggering too easily
band_size 15 Width of each colour stripe in chase Smaller = tighter stripes, Larger = wider bands
CLOSE_CM 50 Distance (cm) that triggers sensor Increase for bigger trigger zone, decrease for closer only

🔧 Troubleshooting Guide
❌ Can't SSH — "Connection refused" or "Host is down"
Pi is not on the network, has a different IP, or SSH isn't running
Step 1 — Check Pi has power (red light on)
Step 2 — Ping it: ping skirtpi4.local
Step 3 — Find new IP: arp -a
Step 4 — Try by name: ssh tammyh@skirtpi4.local
Step 5 — Unplug Pi, wait 10 seconds, replug and wait 60 seconds
❌ SSH Warning — "Remote host identification has changed"
Normal after re-flashing the SD card — new card = new SSH key
ssh-keygen -R 192.168.0.117 ssh-keygen -R skirtpi4.local Then connect again normally. Type yes when prompted.
❌ LEDs not lighting up at all
Wiring issue or library not installed
Check 1 — Is the powerbank turned on and outputting power?
Check 2 — Red wire on Pin 2, White/Yellow on Pin 6, Green on Pin 12 (strip) or Pin 33 (rings)
Check 3 — Is there a 330Ω resistor on the green data wire?
Check 4 — Install libraries: sudo pip3 install --break-system-packages adafruit-blinka rpi_ws281x adafruit-circuitpython-neopixel
❌ Only the first ring lights up
Chain is broken — data not passing from ring 1 to ring 2
Check 1 — Unplug and firmly replug the JST connector between ring 1 and ring 2
Check 2 — Green (data) wire on ring 1's female JST must go to DOUT pad (not DIN)
Check 3 — Bypass ring 1: plug ring 2 directly to Pi to confirm ring 2 itself works
Check 4 — Run chain_test.py and watch where the waterfall stops — that's the break
❌ Pi crashes or freezes mid-session
Power issue — Pi and LEDs sharing a powerbank that can't supply enough current
Fix 1 — Keep Pi on its own dedicated power source (separate from LEDs)
Fix 2 — Reduce brightness in sparkle.py (BRIGHTNESS = 0.3 or lower)
Fix 3 — Don't run full white on all LEDs — it draws the most power
Fix 4 — If Pi won't boot: unplug, wait 10 seconds, replug
❌ SD card corrupted — Pi has red light but no green
Power was cut while Pi was writing to the SD card
Re-flash the SD card with Raspberry Pi Imager:
— Hostname: skirtpi4 · Username: tammyh
— WiFi: your 2.4GHz network — tick Hidden Network checkbox
— Enable SSH with password
After re-flash: mkdir project-sparkle, reinstall libraries, paste code again
❌ Service not starting on boot
Service file not enabled, or sparkle.py has an error
Check logs: sudo journalctl -u sparkle.service -n 50
Re-enable: sudo systemctl enable sparkle.service
Test manually first: sudo python3 ~/project-sparkle/sparkle.py
❌ Mic not triggering LEDs
Threshold too high, or mic not detected
Step 1 — Run mic_test.py first to confirm mic is working
Step 2 — Lower MIC_THRESHOLD in sparkle.py (try 1500 instead of 3000)
Step 3 — Make sure USE_MIC = True in sparkle.py
Step 4 — Check mic is plugged into USB before running the program
❌ "No such file or directory" when running a script
File wasn't created on the Pi, or wrong path
Check the file exists: ls ~/project-sparkle/
If missing, paste it again using the cat method
Always use the full path: ~/project-sparkle/sparkle.py
❌ "Permission denied" when writing system files
sudo doesn't apply to the > redirect operator
Use tee instead of redirect:
cat << 'EOF' | sudo tee /path/to/file your content here EOF
🔌 Hardware Quick Reference
Component Power Data Pin Notes
300 LED Strip Powerbank 1 GPIO18 (Pin 12) 330Ω resistor on data wire. Red→Pin 2, GND→Pin 6
11 LED Rings (276 LEDs) Powerbank 2 GPIO13 (Pin 33) 330Ω resistor on data wire. Daisy-chained DOUT→DIN
8×32 LED Matrix Powerbank 2 GPIO10 (Pin 19) WS2812B type. SPI must be enabled on Pi
Distance Sensor (HC-SR04) 3.3V (Pin 17) TRIG→GPIO23 (Pin 16), ECHO→GPIO24 (Pin 18) Use 3.3V not 5V — 5V will damage it!
USB Microphone USB port USB (automatic) Plug in before running sparkle.py
Raspberry Pi 4 Powerbank 2 (USB-C) — Always shutdown before unplugging
⚠️ Common ground rule: Both powerbanks must share a GND connection with the Pi. Run a wire from powerbank 1 GND to a Pi GND pin, otherwise the strip data signal has no reference.
