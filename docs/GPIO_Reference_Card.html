⚠️ Important Notes

• Always use a 330Ω resistor on every DATA wire

• Strip and Rings are on separate powerbanks

• Both powerbank GNDs must share a common ground with the Pi

• USB mic plugs straight into any USB port

• Strip VCC — hardwired directly to powerbank 1 cord (not on Pi)

• Matrix VCC — hardwired directly to powerbank 2 cord (not on Pi)

• Ring VCC — Pin 2, hardwired before showcase

• Distance sensor VCC — Pin 4, only VCC wire on Pi

• Matrix needs SPI enabled — run sudo raspi-config → Interface Options → SPI
